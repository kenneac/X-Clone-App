X Clone App - Backend API Documentation

1. Backend Overview

The backend of the X Clone App is a robust, RESTful API built with Node.js and Express.js. It serves as the core engine for user interactions, social networking features, and data management.

Main Purpose: To handle user authentication (via Clerk), manage social posts, process comments, track user relationships (followers/following), and deliver real-time-like notifications.

Overall Architecture: The application follows a Model-View-Controller (MVC) inspired architecture tailored for APIs (Model-Route-Controller). It uses MongoDB with Mongoose for data persistence, Cloudinary for media storage, and Arcjet for security/rate-limiting middleware.

6. API Architecture

The API is organized into domain-specific resource groups mapped under the /api prefix.

Route Groups
  • /api/users - User profiles, follow/unfollow actions, suggestions.
  • /api/posts - Create, read, update, delete posts, and likes handling.
  • /api/comments - Manage comments on specific posts.
  • /api/notifications - Fetch user notifications and mark them as read.

10. External Services

  • Clerk: Provides robust identity and access management. Handled via standard middleware provided by Clerk.
  • Cloudinary: Used for image hosting (profile pictures, post images). Handled via cloudinary.js config and upload.middleware.js.
  • Arcjet: Application security layer, providing bot protection and rate limiting integrated at the middleware level.
  • MongoDB Atlas (implied): Cloud-hosted NoSQL database used for persistent data storage.
